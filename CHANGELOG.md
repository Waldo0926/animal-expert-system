# Changelog

## 2.0.0 - 2026-09-13

- Reimplemented the project around a fixed-point forward-chaining inference engine.
- Migrated the production-rule knowledge base to structured JSON.
- Added immutable domain models and knowledge-base validation.
- Added dependency-free CLI and optional bilingual PyQt5 GUI.
- Added tests for all seven animal classifications and multi-hop inference.
- Added GitHub Actions CI and bilingual documentation.
- Removed original coursework artifacts, personal identifiers, bundled environment, compiled executable, and IDE metadata from the public version.
