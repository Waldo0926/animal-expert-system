# Coursework origin and 2026 refactor

This repository is a **new implementation** based on the knowledge-domain idea of a team coursework project completed for an Introduction to Artificial Intelligence practice week in 2022.

The original coursework demonstrated a small production-rule animal identification system. The public repository intentionally does **not** include the original team report, student IDs, bundled virtual environment, compiled executable, IDE metadata, or the old generated GUI source.

## What was modernized in 2026

- Reimplemented the reasoning core as a true forward-chaining engine.
- Separated inference logic from UI code.
- Migrated the knowledge base from positional text parsing to structured JSON.
- Added validation, immutable domain models, CLI support, and automated tests.
- Added a bilingual PyQt5 interface.
- Added packaging metadata and GitHub Actions CI.
- Added English and Simplified Chinese documentation.
